Политика конфиденциальности

«Српски од нуле» · вступила в силу 2 октября 2026 · v2.25.0

Коротко: приложение работает без аккаунтов, без аналитики и без рекламы. Весь ваш прогресс хранится только на вашем устройстве. Разработчик не имеет доступа к вашим данным.

1. Что хранится и где

Прогресс обучения (слова, серия дней, XP, настройки, копилка ошибок) — локально: в localStorage приложения и в резервной автокопии (IndexedDB). На Android система дополнительно резервирует эти данные в ваш личный Google Drive средствами платформы (Android Auto Backup) — доступ есть только у вас. Приложение не имеет серверов и не отправляет прогресс по сети.

Загруженные пакеты озвучки хранятся локально и служат только для звука без интернета.

2. Сетевая активность

  • Обновления — проверка версии и загрузка APK с GitHub (srpski-packs).
  • Докачка пакетов озвучки — ZIP-паки с того же публичного репозитория.
  • Дневник разработки — открытие по вашей кнопке.

Приложение не передаёт третьим лицам ничего, кроме стандартных запросов этих файлов. GitHub видит ваш IP по своим правилам.

3. Микрофон

Только для упражнения «Говорение». Аудио обрабатывается на устройстве (встроенная модель Whisper или системный распознаватель). Записи не сохраняются и не отправляются. Разрешение отзывается в настройках системы.

4. Журнал и сообщения о сбоях

Журнал (по желанию) — технические события и ошибки, хранится локально. Покидает устройство только по вашей инициативе: кнопка «В Telegram»/«Экспорт в файл» или автоотчёт при сбое (хвост журнала, не чаще раза в 2 минуты, только при включённом логировании). В журнале нет имени, контактов и прогресса.

5. Напоминания

Локальное уведомление самого устройства, без сети. Включается только вашим нажатием (онбординг/настройки) и выключается там же.

6. Чего нет

Аккаунтов и регистрации · аналитики · рекламы · трекеров · доступа к контактам и файлам (кроме выбранного вами файла импорта).

7. Удаление данных

Настройки → «Сбросить весь прогресс», либо удалить приложение — система удалит все локальные данные. Резервная копия в Google Drive управляется настройками Android (Настройки → Google → Резервное копирование).
